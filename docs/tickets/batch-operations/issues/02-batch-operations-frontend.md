# 02 — 批次操作:文章列表勾選模式 + 批次工具列

**What to build:** 文章列表新增勾選模式與批次工具列,支援批次刪除、批次設分類、
批次加標籤三個動作,並清楚呈現部分失敗的結果。

**Blocked by:** 01 — 批次操作:batchDeleteArticles / batchSetArticlesCategory /
batchAddTagsToArticles

**Status:** ready-for-agent

**驗收方式:** 部署後手動操作、對照下列具體行為。

- [ ] 新增「選取」按鈕切換勾選模式,開啟後每張文章卡片顯示 checkbox(平常
      隱藏,不干擾一般點擊進入詳情頁的既有互動)。
- [ ] 至少勾選一篇文章時,批次工具列出現,顯示「刪除」「設分類」「加標籤」
      三個動作。
- [ ] 「刪除」:確認對話框列出所有勾選文章的標題(不是只顯示數量),確認後
      呼叫 `batchDeleteArticles`。
- [ ] 「設分類」:選擇目標分類(含「未分類」選項)後,用一行文字(數量 + 目標
      分類名稱)輕量確認,確認後呼叫 `batchSetArticlesCategory`。
- [ ] 「加標籤」:輸入一個或多個標籤後,呼叫 `batchAddTagsToArticles`。
- [ ] 三個動作完成後,回傳結果全部成功時顯示成功提示、重新整理列表、清空
      勾選;有部分失敗時清楚顯示「N 篇成功、M 篇失敗」與失敗原因,同樣重新
      整理列表並清空勾選(讓成功的部分反映出來)。
- [ ] 換頁、切換篩選條件、或關閉勾選模式時,目前的勾選集合清空。
- [ ] 勾選範圍只限當頁——不提供「跨頁全選」,切換頁面後之前頁面的勾選不會
      殘留。
