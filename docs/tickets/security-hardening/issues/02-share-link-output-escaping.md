# 02 — 修掉分享連結的輸出跳脫漏洞

**What to build:** 分享連結網址帶入的參數,不管內容是什麼,都不可能在開啟連結的人瀏覽器裡變成真正
執行的程式碼。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 分享連結帶入的文章 ID 改成透過頁面既有元素的資料屬性,搭配平台本身會依輸出情境自動跳脫的
      樣板標籤輸出,取代目前手動組字串、再用不跳脫樣板標籤直接輸出的做法
- [ ] 前端啟動邏輯改成從該資料屬性讀值,下游依文章 ID 開啟文章詳細畫面的行為維持不變
- [ ] 手動驗收清單新增項目:用帶有可執行內容片段的分享連結參數實測,確認不會執行到任何非預期
      程式碼
- [ ] `README.md`「已知問題修復紀錄」新增對應條目,說明樣板標籤輸出跳脫情境的根因與修法
- [ ] 新增/修改的說明註解不含任何完整且具語法作用的角括號寫法
