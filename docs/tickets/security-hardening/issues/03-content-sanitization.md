# 03 — 文章內容與附件顯示前的消毒

**What to build:** 文章內文、Markdown 檔案型附件的預覽內容、AI 問答的回答內容,這三處在畫面上顯示前
都會先經過消毒,內容裡夾帶的可執行程式碼不會被執行,且既有的語法上色效果不受影響。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 引入一套業界標準的 HTML 消毒函式庫,透過既有第三方函式庫載入方式引入(跟目前載入 Markdown
      渲染/語法上色/編輯器函式庫的方式一致)
- [ ] 文章內文顯示前的 Markdown 轉換結果先經過消毒再顯示
- [ ] Markdown 檔案型附件預覽的內容先經過消毒再顯示
- [ ] AI 問答回答內容先經過消毒再顯示
- [ ] 手動驗收清單新增項目:以帶有可執行內容片段的 Markdown 內容實測上述三處,確認不會執行到任何
      非預期程式碼,且既有語法上色效果不受影響
- [ ] `README.md`「已知問題修復紀錄」新增對應條目
- [ ] 新增/修改的說明註解不含任何完整且具語法作用的角括號寫法
