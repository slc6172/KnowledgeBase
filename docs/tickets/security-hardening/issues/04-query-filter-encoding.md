# 04 — 統一資料庫查詢條件的編碼

**What to build:** 所有組出資料庫過濾條件字串的地方,一律透過共用輔助函式對值做正確編碼,特殊字元
不會再有機會影響查詢語意。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] SupabaseClient 模組新增共用的 filter 組裝輔助函式(涵蓋等於比對與清單比對兩種型式),內部對
      值做正確的 URL 編碼
- [ ] 所有目前用手動字串相加組出等於比對、清單比對這類過濾條件的呼叫端,全部改用這組輔助函式,
      不限於目前已知會吃自由文字輸入的欄位,作為縱深防禦
- [ ] 針對含特殊字元的值補上對應測試案例,驗證組出的過濾條件確實正確編碼
- [ ] 既有測試套件維持綠燈
- [ ] `README.md`「已知問題修復紀錄」新增對應條目
- [ ] 新增/修改的說明註解不含任何完整且具語法作用的角括號寫法
