# 01 — 收斂寫入操作與泛用資料庫代理函式的曝光邊界

**What to build:** 所有寫入函式、泛用資料庫存取函式,以及一次性初始化/診斷函式,全部不再能被密碼
驗證入口以外的方式直接呼叫;新增一個靜態迴歸測試,確保這個曝光邊界以後不會在無意間被破壞。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 白名單裡的寫入函式全部改成不會被平台自動暴露給前端呼叫的私有函式,唯一對外入口維持是密碼
      驗證後的轉呼叫機制,對外操作名稱不變,前端呼叫方式不需要調整
- [ ] SupabaseClient 模組對外提供的泛用資料庫存取函式(含底層泛用代理)同樣改成不會被自動暴露的
      私有函式
- [ ] 一次性初始化函式與純診斷函式同樣改成不會被自動暴露的私有函式,並在函式定義附近以純中文說明
      手動觸發的替代做法(不使用任何具語法作用的角括號寫法)
- [ ] 新增靜態迴歸測試,讀取後端模組原始碼文字,斷言這批函式宣告都帶有平台規定的私有字首,測試
      失敗時列出目前不符合規則的函式清單
- [ ] 現有測試套件(含間接引用到這些函式名稱的測試檔案)全數更新並維持綠燈
- [ ] `README.md`「已知問題修復紀錄」新增對應條目,說明「平台曝光邊界」這個根因與修法
- [ ] 新增/修改的說明註解不含任何完整且具語法作用的角括號寫法
