# 02 — 前端:檢索到的相關文章改為預設收合面板、文件

**What to build:** AI 回答下方的來源區改成預設收合的原生展開面板:標題列「檢索到的相關文章(N)」,
展開後是垂直列表,每列顯示文章標題與分類名稱,點擊開啟該文章。舊的膠囊樣式移除。最後更新
README 變更紀錄與 CLAUDE.md。

**Blocked by:** 01 — `sources` 新增 `categoryName`

**Status:** done

**接縫(spec〈Testing Decisions〉接縫 2):** 前端靜態文字掃描(讀 `src/*.html` 原始碼)+ 部署後手動實測;
另沿用既有 prior art,在 jsdom 執行 `renderAiAnswerTurn` 驗證渲染結果。

**手動驗證:** spec 手動驗證清單(含約 375px 窄螢幕):預設收合;展開為垂直列表;20 篇可捲動不撐破版面;
長標題換行;未分類無殘留分隔符;點擊開啟文章;下一輪回答回到收合;鍵盤可展開與選取;查無資料不出現面板。

- [x] 有來源時渲染一個原生展開元素,渲染時不帶展開屬性(預設收合)
- [x] 摘要文字含「檢索到的相關文章」與來源數量
- [x] 展開內容為垂直列表,每列一個按鈕:主要文字為標題,次要文字為分類名稱;
      分類為空時完全不渲染次要文字與其分隔符
- [x] 點擊某列呼叫既有的開啟文章行為並帶入該文章 id
- [x] 標題與分類名稱以純文字方式設定,不經字串拼接進 HTML
- [x] 列表按鈕最小高度規則 ≥ 44px、長標題自動換行;來源列表不另設筆數上限,
      維持既有 AI 回答區塊的捲動行為
- [x] 每次渲染新一輪回答都重新建立面板(回到收合);查無相關資料時不出現面板、
      原訊息不變;對話歷史累積邏輯不變
- [x] 舊的膠囊 class 已不存在於腳本與樣式;新樣式只使用既有設計 token;
      摘要列有可操作外觀(指標樣式與聚焦樣式)
- [x] README 新增變更紀錄一條;CLAUDE.md「進行中」移除本 spec;文件不寫測試總數

> **實作註記:** 新增輔助函式 `buildAiSourcesPanel`(由 `renderAiAnswerTurn` 呼叫),讓面板建構可獨立在 jsdom 驗證。
> 新 class 命名為 `ai-sources*`(而非沿用 `ai-answer__source*` 前綴),使「舊膠囊 class 已不存在」的靜態掃描能乾淨成立。
> 破壞驗證:預設展開、標題改用 innerHTML、無分類仍渲染次要元素、min-height 縮到 30px,四種改動都會使測試變紅。
