# 02 — 標籤管理補完:標籤管理頁

**What to build:** 新增標籤管理視圖,列出所有標籤,支援改名、刪除(先顯示
影響文章數再確認)、合併至另一個標籤。互動模式比照既有的分類管理頁(view/edit
row 切換),不是全新設計。

**Blocked by:** 01 — 標籤管理補完:renameTag / deleteTag / countTagUsage /
mergeTags

**Status:** ready-for-agent

**驗收方式:** 部署後手動操作、對照下列具體行為。

- [ ] 新增進入標籤管理頁的入口按鈕(比照 `#btn-category-manager` 的既有位置與
      風格),進入時呼叫 `listTags()` 列出所有標籤。
- [ ] 每個標籤列有「改名」控制項(輸入框 + 儲存/取消),呼叫 `renameTag`,
      成功後畫面即時反映新名稱。
- [ ] 每個標籤列有「刪除」按鈕:點擊後先呼叫 `countTagUsage(tagId)`,用回傳的
      數量組出確認訊息(「這個標籤目前用在 N 篇文章,確定要刪除嗎?」),確認後
      才呼叫 `deleteTag`,成功後該標籤從清單移除。
- [ ] 每個標籤列有「合併至…」控制項:展開一個可選擇目標標籤的下拉選單
      (排除自己),選定後呼叫 `mergeTags(這個標籤.id, 選的目標.id)`,成功後
      來源標籤從清單移除、清單其餘部分保持正確。
- [ ] 任一動作(改名/刪除/合併)失敗時,畫面上有清楚可見的錯誤訊息。
- [ ] 合併後,回到文章編輯頁的標籤自動建議(既有的 `renderTagSuggestions`)
      不再顯示已經被合併掉的來源標籤。
