# 02 — 相關文章推薦:詳情頁「你可能也想看」區塊

**What to build:** 文章詳情頁新增「你可能也想看」區塊,載入文章詳情的同時呼叫
`getRelatedArticles(articleId)`,顯示語意最相近的其他已發布文章,點擊可以直接
切換過去。

**Blocked by:** 01 — 相關文章推薦:related_articles RPC + GAS 函式

**Status:** ready-for-agent

**驗收方式:** 部署後手動操作、對照下列具體行為。

- [ ] 開啟一篇有相關文章的已發布文章詳情頁,自動顯示「你可能也想看」區塊,
      列出最多 3 篇相關文章(標題 + 分類,不需要完整卡片的 snippet/tags/狀態
      徽記)。
- [ ] 沒有相關文章時(知識庫文章太少或都不相關、RPC 回傳空陣列),整個區塊
      不顯示,不留下空標題或「沒有相關文章」的空狀態文字。
- [ ] 點擊任一張相關文章卡片,直接切換到那篇文章的詳情頁(呼叫
      `openArticleDetail`),並且該篇文章自己的「你可能也想看」區塊也正確載入
      (不是停留在舊資料)。
- [ ] 草稿文章(沒有 `embedding`)的詳情頁不會因為這個區塊而報錯或卡住——
      `getRelatedArticles` 呼叫失敗或回傳空陣列時,頁面其餘部分(標題、內容、
      附件)正常顯示。
- [ ] 這個區塊的載入不會阻塞或延遲文章本文/附件面板的顯示(平行呼叫,不是
      等它做完才顯示文章內容)。
